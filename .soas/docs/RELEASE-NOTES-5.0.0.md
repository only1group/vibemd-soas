# VibeMD SOAS 5.0.0

SOAS 5.0 makes the framework repeatable and evidence-controlled while
preserving its instruction-native architecture.

Highlights:

- strict executable capability and output contracts;
- deterministic scope selection with recorded exclusions and dependencies;
- domain-specific objectives, evidence and test recipes for all capabilities;
- immutable execution context and explicit capability outcomes;
- evidence fitness, calibrated severity and safe active-testing protocols;
- independent closure semantics, including AI-agent context limitations;
- complete reference validation and golden self-assurance fixtures.

This is a breaking contract release. Follow `docs/MIGRATION-4-TO-5.md`. No
consuming application runtime is introduced.
