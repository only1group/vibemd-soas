# VibeMD SOAS 4.0.0

- Clean greenfield package with no legacy directory or legacy audit identifiers.
- Removed the module concept; all assurance logic is represented as capabilities.
- Added 72 standardised capability definitions.
- Added Guided Engineer and Lead Peer paths.

- Added global standards registry and optional Australia, United States and European overlays.
- Explicitly excluded industry-specific frameworks from the base product.
- Added controlled learning and permission-based self-healing protocols.
- Added professional report, register, ADR, execution and remediation contracts.
