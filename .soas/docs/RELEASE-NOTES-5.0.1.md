# VibeMD SOAS 5.0.1

SOAS 5.0.1 corrects and strengthens standards registry resolution.

Highlights:

- ISO 22301 includes Amendment 1:2024 while the next-edition draft remains
  advisory;
- ISO 31000 remains pinned to the current 2018 final;
- generic ISO 9241 mappings are replaced by the applicable published parts;
- all machine-readable YAML framework references are checked against the
  standards or jurisdiction registries;
- duplicate and unknown identifiers fail validation;
- offline resolution is regression-tested against exact pinned finals.

This is a compatible patch release. No consuming application runtime is
introduced and no restricted normative standards text is distributed.
