# Package Structure

- `SOAS.md`: master Lead Architect instruction.
- `START-HERE.md`: beginner and senior-engineer entry guide.
- `profiles/`: interaction styles; assurance depth remains constant.
- `journeys/`: ordered compositions of capabilities.
- `capabilities/`: the complete executable instruction library. Each capability is YAML.
- `catalogue/`: searchable index used by the orchestrator.
- `orchestrator/`: planning, questioning, evidence, standards and closure protocols.
- `standards/`: authoritative registry, mapping rules and optional jurisdiction overlays.
- `knowledge/`: controlled core, project and organisation knowledge.
- `templates/`: professional reports, registers, decisions, plans and remediation prompts.
- `schemas/`: machine-checkable output contracts.
- `examples/`: copy-and-paste invocations.
